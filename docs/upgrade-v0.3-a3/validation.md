# Validation

Baseline a2 has 328 tests. Twenty-four new regressions cover work boundary
preview/mutations, same-window and competing-worktree races, client/provider
routing replay, stale/expired/moved/blocked ownership, pending inbox/decisions,
Git redirect isolation, guard rollback, notification retries/rollback, actual
CLI startup and real stdio MCP cycles. Edition tests compare exact file kinds,
repeat installation, preserve conflicts and reject incompatible switches.

Run 352 source and independently installed-wheel tests, config/manifests,
JSON/YAML and relative Markdown links, native plugin validators and mirrored
Skill checks. Require Ubuntu/Windows Python 3.10/3.13 CI on the final head.
Published artifacts need version-specific PyPI readback, checksum/content match,
fresh installation and actual demo/CLI/MCP workflow calls after publication.

These checks establish local cooperative behavior, not live model/provider access,
native client GUI connections, global ownership or automatic client wakeups.
