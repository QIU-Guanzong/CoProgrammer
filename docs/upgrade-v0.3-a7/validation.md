# Validation scope

Exercise real foreground processes and Git worktrees: dependency completion,
incoming handoffs while waiting, explicit receipts followed by tasks, same-scope
successive edits, durable notifications, child Manager access, duplicate watcher
exclusion, failure/no retry, bounded timeout, scope retention and POSIX SIGINT.
Existing runner timeout tests cover Windows process-tree cleanup.

Startup tests cover read-only preview, preserved instructions, configuration
conflicts preventing registration, explicit resume, setup failure and registration
failure after installation. Native checks reject a launcher reporting another or
missing profile path before probing and support explicitly selected executables.

Full source and independently installed package suites, Skill equivalence,
configuration/JSON/Markdown checks, Windows/Linux CI and public package readback
are release gates. Reuse the isolated package environment; preserve immutable
receipts and latest/rollback wheels. Logs/fixtures/envs are retired only by exact
task-owned whitelist after process/reference checks.

Native evidence concerns explicit local OpenClaw 2026.6.8. The default launcher
observed during a6 publication routes to a managed 2026.10.2 service and ignores
local profile variables; it remains untouched. There are no model calls or new
WorkBuddy GUI checks, and no autonomous model/productivity/adoption claims.
