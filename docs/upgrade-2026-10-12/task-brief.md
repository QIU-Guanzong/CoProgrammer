before understanding two-window task ownership, conflict checks and handoffs.

README that demonstrates a concrete problem and a reproducible first journey.

config overwrite, terminal hooks, distributed ownership and external outreach.

eligibility, stale/blocked attention, unchanged messages/tokens, UTF-8 output,
stdio MCP, full source/installed-wheel suites and existing cross-platform CI.
