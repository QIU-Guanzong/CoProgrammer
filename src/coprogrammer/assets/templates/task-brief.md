# Task brief

Copy this template into the task's review artifacts. Replace each instruction
with the concrete scope; a blank template does not authorize edits.

## Intent

Describe the user's requested outcome and observable acceptance criteria.

## Ownership and scope

Record task ID, creator, assigned window and worktree. List allowed paths,
excluded paths, prerequisites and shared contracts. Match the registered task's
scope; record changes explicitly before editing outside it.

## Validation

List the repository checks and user journeys that establish the outcome.
Identify protected areas requiring review and any checks that cannot run here.

## Handoff

State the expected artifacts, review recipient and remaining decisions within
the user's authorized workflow. Link actual results when work completes.
