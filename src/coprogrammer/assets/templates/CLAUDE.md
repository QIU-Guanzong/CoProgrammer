Read `docs/coprogrammer/COORDINATION.md` when coordinating development with
other windows or clients. Use the configured CoProgrammer MCP tools, or the
matching CLI if available, for shared task claims, guards and messages.

CoProgrammer setup does not enable native Claude teams or cross-session
messaging. Read current shared state explicitly; a saved message does not
guarantee that another client is awake. Preserve existing project instructions
when incorporating this guidance.
